## Lookup Alamat PKB

## Alur

1. gabung.py: gabung PKB Details 2025 & 2026, lookup ke Address Final by nomor WO
2. perbaiki.py: perbaiki 7 file 2025 yang korup
3. cek.py / cek2.py: cek kelengkapan alamat

## Hasil

- 2025: 1.803.574 baris, 2026: 1.401.589 baris
- ~70% baris punya kecamatan/kota/provinsi
- ~30% (153.849 PKB unik) belum: 78% ada di belum_lengkap (mayoritas tidak teridentifikasi), 22% tidak ada di file alamat mana pun
- 7 file 2025 sempat korup, sudah diperbaiki, kemungkinan ada baris di ujung yang hilang
